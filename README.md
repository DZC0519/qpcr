# qPCR 分析助手 2.1

一款完全离线的简体中文 Windows 桌面工具，用 Excel / GraphPad Prism 式流程完成 96/384 孔 qPCR 相对定量分析。

## 主要能力

- 自动识别 Cp/Cq/Ct、Pos/Well 及第 2 行等非首行表头，多工作表可选择。
- 组别默认是 Ctrl、Model、Low、Med、High、Pos，可在实验设置页单击编辑、添加或删除；支持 Ctrl 跨行/跨列多选并把组别、样本号和基因精确应用到所选孔。
- 基因在实验开始时统一录入并勾选一个或多个内参；新增行后可直接输入，名称单击即可编辑。
- 2 个及以上可变技术复孔；按可调 Cp 极差检查，唯一异常值才提供一键排除建议。
- 排除值保留原始数据、灰色删除线显示、可手动排除/恢复、可撤销并写入工程记录。
- 每个靶基因一个底部工作表标签，显示 Ct → ΔCt → 校准 → ΔΔCt → Fold change。
- 可直接在计算表多选样本行排除或恢复，校准组、Fold change 和统计立即同步重算。
- Fold change 点柱状图默认折叠且使用 SEM，可选 SD/95% CI/无误差线；有 Model 时标注 Ctrl/各处理组与 Model 的原始 P 星号，无 Model 时回退到 Ctrl。
- 可复制单张图片或为当前基因导出可编辑 SVG；公式化 Excel 不包含分析页已排除的样本行。

## 启动

便携版解压后双击 qPCR分析助手.exe，无需安装 Python。源码方式安装 requirements.txt 后运行 python -m qpcr_analyzer。

## 分析边界

当前版本不处理跨板归一化、绝对定量、扩增效率估算、配对/重复测量和熔解曲线判断。
