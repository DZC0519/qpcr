# qPCR 分析助手 2.1：快速使用指南

## 1. 导入和基因设置

拖入 .xlsx/.csv，或点击整块蓝色虚线区域选择文件。确认工作表后，一次性录入本次实验的所有基因，勾选一个或多个内参。点击“添加基因”即可直接输入，已有名称单击即可修改；常用基因可保存在本机。原始 Cp 和机器元数据不会被修改。

## 2. 板图分配

框选孔位时会显示半透明蓝色区域、粗蓝边框、行列标题高亮和孔数/行列范围。需要间隔选择时按住 Ctrl 继续框选，例如可同时选择 B10:B12、D10:D12、F10:F12。先在实验设置页编辑本次组别，再选择组别和样本号，点击“应用组别/样本到所选孔”，只修改当前选中的孔，未选孔保持不变；随后可直接点击“应用基因到所选孔”。横向连续孔按从左到右编号技术复孔，纵向连续孔按从上到下编号，间隔行或间隔列不会再造成方向误判。旧项目需要整行或整列扩展时使用“整行/整列分组”。选择结果、精确选孔模式、组别列表和复孔方向都会保存到工程和模板。96/384 孔板均保留完整行列；板图默认保持 85% 的大孔块布局，白色滚动条略微加宽，便于拖动。

## 3. 复孔 QC

默认极差阈值 0.5 Cp，排除后至少保留 2 个有效复孔。只有不少于 3 个有效值、存在距离中位数最远的唯一孔、且移除后极差恢复合格时，才给出自动排除建议。两个复孔差异过大、最远值并列或移除后仍不合格时只提示人工判断。双击任意 Cp 可手动排除或恢复。

## 4. 分析与作图

每个靶基因一个标签。计算为 ΔCt = Ct_target - Ct_reference，ΔΔCt = ΔCt - 当前校准组平均 ΔCt，Fold change = 2^-ΔΔCt。默认校准组为 Ctrl，也可在实验设置中重命名；多内参取各内参技术复孔均值后的平均值。缺少目标、任一内参、有效复孔或足够校准组样本时显示“不可计算”。

计算表是分析页主体，可多选样本行后点“排除选中”，也可恢复选中或全部恢复。排除后校准组、Fold change、统计、图形和 Excel 同步重算。图表默认折叠，点击“显示图表”后以正常比例展开；柱为组均值，点为独立生物样本，误差线默认 SEM。有 Model 时，图中只标注校准组 vs Model 以及各处理组 vs Model；没有 Model 时回退为各组 vs 校准组。显著结果以对应柱上方的短横线和星号紧凑显示，不绘制跨越多组的长线，也不显示 ns。星号使用统计表中的原始 P 值，BH 校正 P 与 BH 显著性继续保留在统计折叠表中；“复制图片”可直接粘贴到 Word、PowerPoint 或绘图软件。

## 5. 导出

“清理后计算表”按靶基因建立工作表，且不会写入分析页已经排除的样本行。ΔCt、校准组平均、ΔΔCt、Fold change 为可见 Excel 公式，Ct 批注列出保留孔和 QC 排除孔；最后仅增加“排除记录”。单张 SVG 在对应基因分析页导出。

## 统计规则

技术孔不作为独立重复。两组使用 Welch t 检验；三组及以上使用 Welch ANOVA 与 Games–Howell；跨基因/比较计算 BH 校正。检验在 ΔCt 尺度完成。图中星号读取统计表的原始 P 列；三组及以上时该列为 Games–Howell 事后比较 P，本身已考虑组间多重比较。作图误差线默认 SEM，也可切换为 SD、95% CI 或无误差线；各误差线均从 ΔCt 尺度计算后反变换。
